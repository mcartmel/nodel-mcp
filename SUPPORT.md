# Support Policy

This repository is an unsupported public preview. It is an independent,
community-visible integration with no support commitment, service-level
agreement, or guarantee that issues or pull requests will be reviewed.

[Issues](https://github.com/mcartmel/nodel-mcp/issues) and
[pull requests](https://github.com/mcartmel/nodel-mcp/pulls) may contain bug
reports and reproducible improvement proposals, but acceptance,
review, and response are discretionary. Do not use public issues for security
vulnerabilities; follow [SECURITY.md](SECURITY.md).

The supported baseline is Linux, Node.js 22, systemd, and upstream Nodel
`v2.2.1.542`. Other environments and Nodel versions are best effort.
